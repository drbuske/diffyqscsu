    Handout Daily Prep 5.1 - Introduction to Systems of ODEs
    

    Section Overview

    We now introduce the idea of a system of ordinary differential equations, which arises whenever there are multiple dependent variables whose rates of change may influence one another. Instead of a single function \(y(x)\text{,}\) we may have several functions \(y_1, y_2, \ldots, y_n\) governed by multiple differential equations, each involving the variables and their derivatives. The section explains that systems can be of various orders—first‑order systems being the most common—and solutions consist of a collection of functions that simultaneously satisfy all equations in the system. Initial conditions must specify all dependent variables (and possibly their derivatives) at a given point. The section includes simple examples showing how some systems can be solved by decoupling: solving one equation first and then substituting into the others. This introduces the basic terminology and structure that lead naturally to matrix methods and linear systems in later sections.
    🔗
    🔗

    Exercises Exercises

    1. What is a system of ODEs?
    Which of the following best describes a system of ODEs?
    🔗
    • A collection of differential equations involving several dependent variables \(y_1, y_2, \ldots, y_n\) and their derivatives.
    • Correct. A system consists of multiple ODEs involving several dependent variables.
    • A single equation that has more than one independent variable.
    • Incorrect. Systems involve *several dependent variables*, not multiple independent variables.
    • Any ODE with order greater than one.
    • No. Higher-order ODEs are not necessarily systems.
    🔗
    2. What is a solution to a system?
    For a first-order system \(x_1' = g_1(x_1, x_2, x_3, t),\ x_2' = g_2(x_1, x_2, x_3, t),\ x_3' = g_3(x_1, x_2, x_3, t) \text{,}\) what does it mean to be a solution?
    🔗
    • A triple of functions \(x_1(t), x_2(t), x_3(t)\) that satisfies all three equations simultaneously.
    • Correct. A solution consists of functions that satisfy every equation in the system.
    • Any function \(x(t)\) that satisfies at least one equation.
    • No. A solution must satisfy *all* equations in the system.
    • Only \(x_1(t)\) must satisfy its equation; the other functions may be arbitrary.
    • Incorrect. Every dependent variable must satisfy its own ODE.
    🔗
    3. Initial Conditions for Systems.
    For a system with dependent variables \(x_1, x_2, x_3\text{,}\) what do appropriate initial conditions look like?
    🔗
    • Values for each dependent variable at a point, such as \(x_1(0)=a_1\text{,}\) \(x_2(0)=a_2\text{,}\) \(x_3(0)=a_3\text{.}\)
    • Correct. An initial condition must specify each variable’s value at the starting time.
    • Only one initial value is needed, since the equations are linked.
    • No. Each variable requires its own initial value.
    • Only derivatives need initial values.
    • Incorrect for first-order systems; values of the variables themselves must be specified.
    🔗
    4. Determining the Order of a System.
    Consider the system
    \begin{align*} y_1'' \amp = y_2' + y_1, \\ y_2'' \amp = 3y_2. \end{align*}
    What is the order of this system?
    🔗
    • Second-order, because the highest derivatives in the system are second derivatives.
    • Correct. The section explains that the order of a system is the highest derivative appearing in any of the equations.
    • First-order, because there are two equations.
    • No. The number of equations does not determine order.
    • Fourth-order, because two second derivatives add up to order four.
    • Incorrect. Orders are not added; the system’s order is simply the highest derivative that appears.
    🔗
    5. Understanding a General Solution.
    A system of two first-order ODEs has a general solution
    \begin{align*} x_1(t) \amp = C_1 e^{t}, \\ x_2(t) \amp = C_1 e^{t} + C_2 e^{2t}. \end{align*}
    What does this general solution represent?
    🔗
    • A family of solutions containing two arbitrary constants, one for each initial condition of the system.
    • Correct. For a system with two dependent variables, the general solution contains two constants so that any initial conditions \(x_1(t_0)\) and \(x_2(t_0)\) can be matched.
    • A single solution valid only for the initial condition \(x_1(0)=1\text{.}\)
    • No. This general solution works for any initial conditions.
    • A solution that is valid only when \(C_1 = C_2\text{.}\)
    • No. \(C_1\) and \(C_2\) are independent constants.
    🔗
    6.
    Consider the pair of equations
    \begin{align*} y_1' \amp = 3y_1, \\ y_2' \amp = y_1 + y_2. \end{align*}
    Explain why this pair of equations forms a first-order system of ODEs, and identify the dependent and independent variables.
    🔗
    Solution.
    This is a first-order system because each equation involves only the first derivatives \(y_1'\) and \(y_2'\) and no higher derivatives. A system of ODEs consists of several differential equations involving multiple dependent variables.
    🔗
    The dependent variables are \(y_1\) and \(y_2\text{,}\) and the independent variable is the implied variable (typically \(t\) or \(x\)) with respect to which the derivatives are taken.
    🔗
    🔗
    🔗
    7.
    Suppose we have a first-order system
    \begin{align*} x_1' \amp = g_1(x_1,x_2,t), \\ x_2' \amp = g_2(x_1,x_2,t). \end{align*}
    What does it mean for a pair of functions \(x_1(t), x_2(t)\) to be a solution to this system?
    🔗
    Solution.
    A solution to the system is a pair of functions \(x_1(t)\) and \(x_2(t)\) that satisfy both differential equations for all relevant values of \(t\text{.}\) That is, \(x_1'(t) = g_1(x_1(t),x_2(t),t)\) and \(x_2'(t) = g_2(x_1(t),x_2(t),t)\) simultaneously.
    🔗
    Because the system has two dependent variables, both must satisfy their equations for the pair to count as a valid solution.
    🔗
    🔗
    🔗
    8.
    Consider the system from the section:
    \begin{align*} y_1' \amp = y_1, \\ y_2' \amp = y_1 y_2, \end{align*}
    with initial conditions \(y_1(0)=1\) and \(y_2(0)=2\text{.}\) Solve for \(y_1(t)\) and then use it to find \(y_2(t)\text{.}\)
    🔗
    Solution.
    We begin by observing that the first equation, \(y_1' = y_1\text{,}\) is independent of \(y_2\text{.}\) This makes the system decoupled in the sense described in the section: we can solve for \(y_1\) first and then substitute it into the equation for \(y_2\text{.}\)
    🔗
    Solve \(y_1' = y_1\text{:}\) the general solution is \(y_1(t) = C_1 e^{t}\text{.}\) Apply the initial condition \(y_1(0) = 1\text{:}\) \(1 = C_1 e^0\text{,}\) hence \(C_1 = 1\text{.}\)
    🔗
    Therefore,
    \begin{equation*} y_1(t) = e^{t}. \end{equation*}
    🔗
    Next, substitute \(y_1(t) = e^{t}\) into the second equation \(y_2' = y_1\,y_2\text{.}\) We obtain the first-order linear ODE: \(y_2' = e^{t} y_2.\)
    🔗
    Rewrite this in standard linear form: \(y_2' - e^{t} y_2 = 0.\) The integrating factor is \(\mu(t) = e^{-\int e^{t} \, dt} = e^{-e^{t}}.\) Multiplying through by the integrating factor gives \((e^{-e^{t}} y_2)' = 0.\) Integrating both sides yields \(e^{-e^{t}} y_2 = C_2.\)
    🔗
    Solving for \(y_2\text{,}\) we get
    \begin{equation*} y_2(t) = C_2\, e^{e^{t}}. \end{equation*}
    Now apply the initial condition \(y_2(0)=2\text{.}\) When \(t=0\) we have \(y_2(0) = C_2\, e^{e^{0}} = C_2\, e^{1} = C_2 e.\) Hence \(C_2 = 2/e\text{.}\)
    🔗
    Therefore,
    \begin{equation*} y_2(t) = \frac{2}{e}\, e^{e^{t}} = 2\, e^{\,e^{t}-1}. \end{equation*}
    🔗
    Putting both components together, the solution to the system is
    🔗
    \begin{equation*} y_1(t) = e^{t}, \qquad y_2(t) = 2\, e^{\,e^{t}-1}. \end{equation*}
    🔗
    🔗
    🔗
    🔗
