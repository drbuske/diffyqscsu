    Handout Daily Prep 3.1 - The Laplace Transform
    

    Section Overview

    In this section, we introduce the Laplace transform as a powerful method for solving differential equations by converting them into algebraic equations. We explain how the transform takes a function of time and produces a new function of a frequency-like variable \(s\text{,}\) allowing difficult ODEs to become simpler algebraic expressions that can be solved and then inverted. We also see motivating examples, including its usefulness for handling discontinuous inputs and modeling physical systems such as forced oscillators and electrical circuits.
    🔗
    🔗

    Exercises Exercises

    1. Basic Definition.
    The Laplace transform of a function \(f(t)\) is defined by \(\displaystyle \mathcal{L}\{f(t)\}(s) = \int_{0}^{\infty} e^{-st} f(t)\, dt.\) For what values of \(s\) does this improper integral typically converge?
    🔗
    • For all \(s\) sufficiently large so that the integral converges.
    • Correct. The transform only exists when the improper integral converges, typically for \(s\) in some right half‑plane.
    • For all real numbers \(s\text{.}\)
    • No—the integral may diverge for small or negative \(s\text{.}\)
    • Only for \(s = 0\text{.}\)
    • No—the Laplace transform is designed for \(s\) in a range of positive values.
    🔗
    2. Transform of a Constant.
    What is the value of the transform \(\mathcal{L}\{1\}(s)\) (when it exists)?
    🔗
    • \(\displaystyle \frac{1}{s}\)
    • Correct. The integral \(\int_0^{\infty} e^{-st} dt = 1/s\) for \(s>0\text{.}\)
    • \(\displaystyle \frac{1}{s^2}\)
    • No—that is the transform of \(t\text{,}\) not \(1\text{.}\)
    • \(e^{-s}\)
    • Not correct—the transform is a rational function, not exponential.
    🔗
    3. Linearity of the Laplace Transform.
    Which property does the Laplace transform satisfy?
    🔗
    • \(\mathcal{L}\{a f(t) + b g(t)\} = a F(s) + b G(s)\)
    • Correct. The Laplace transform is linear.
    • \(\mathcal{L}\{f(t)g(t)\} = F(s)G(s)\)
    • No—there is no simple product rule for Laplace transforms.
    • \(\mathcal{L}\{f'(t)\} = f(t)\)
    • No—that contradicts the derivative formula introduced later in the section.
    🔗
    4. Transform of an Exponential.
    Using the definition, what is \(\mathcal{L}\{ e^{at} \}(s)\) (for \(s>a\))?
    🔗
    • \(\displaystyle \frac{1}{\,s - a\,}\)
    • Correct. The integral \(\int_0^\infty e^{-st} e^{at} dt = 1/(s-a)\text{.}\)
    • \(\displaystyle \frac{1}{s+a}\)
    • No—this corresponds to \(e^{-at}\text{.}\)
    • \(\displaystyle s-a\)
    • No—the transform should be a rational function in \(s\text{.}\)
    🔗
    5. Conceptual Purpose of the Laplace Transform.
    What is one main advantage of the Laplace transform in solving ODEs?
    🔗
    • It converts differential equations into algebraic equations in the \(s\)-domain.
    • Correct. Laplace transforms turn calculus problems into algebra problems.
    • It eliminates the need to know initial conditions.
    • No—Laplace transforms actually incorporate initial conditions directly.
    • It provides exact solutions only for nonlinear differential equations.
    • No—it is primarily a tool for linear ODEs with forcing terms.
    🔗
    6. Choosing the Laplace Transform Method.
      Each differential equation below can be solved using different methods. Sort the equations according to whether the Laplace transform is especially well suited for solving the problem.
      🔗
    • \(y'' + y = \begin{cases} 0 \amp 0 \le t < 2 \\ 1 \amp t \ge 2 \end{cases}\)
    • \(y'' + 3y' + 2y = u(t-5)\)
    • \(y'' + y = \delta(t-3)\)
    • Laplace transform is especially useful
    • \(y'' - 4y = e^{2t}\)
    • \(y'' + y = \sin t\)
    • \(y'' - y' = t^2\)
    • Better suited for earlier methods
    🔗
    7.
    If \(f(t)\) is defined for \(t \ge 0\text{,}\) then its Laplace transform is defined by \({\cal L}[f(t)] = ?\text{.}\)
    🔗
    Solution.
    The Laplace transform of \(f(t)\) is
    🔗
    \begin{equation*} {\cal L}[f(t)](s) = \int_{0}^{\infty} e^{-st} f(t)\, dt. \end{equation*}
    The variable \(s\) is generally assumed to satisfy conditions that make the improper integral converge.
    🔗
    🔗
    🔗
    8.
    In your own words, what does it mean for a function to be of exponential order?
    🔗
    Solution.
    A function \(f(t)\) is of exponential order if, for large \(t\text{,}\) it does not grow faster than some exponential \(e^{\alpha t}\text{.}\) More precisely, there exist constants \(M,\alpha\) such that \(|f(t)| \le M e^{\alpha t}\) for all sufficiently large \(t\text{.}\)
    🔗
    This ensures that the Laplace integral will converge for \(s > \alpha\text{.}\)
    🔗
    🔗
    🔗
    9.
    Suppose \(f(t) \equiv 1\) on \([0,\infty)\text{.}\) Compute \({\cal L}[f(t)]\text{.}\) What is the domain of \(F(s)\text{?}\)
    🔗
    Solution.
    Compute directly:
    🔗
    \begin{equation*} {\cal L}[1](s) = \int_{0}^{\infty} e^{-st} dt = \left[ -\frac{1}{s} e^{-st} \right]_{0}^{\infty} = \frac{1}{s}. \end{equation*}
    This converges only if \(s > 0\text{.}\) Thus:
    🔗
    \begin{equation*} F(s) = \frac{1}{s}, \qquad s > 0. \end{equation*}
    🔗
    🔗
    10.
    Suppose \(f(t)=e^{at}\) on \([0,\infty)\text{.}\) Compute \({\cal L}[f(t)]\text{.}\) What is the domain of \(F(s)\text{?}\)
    🔗
    Solution.
    Compute:
    🔗
    \begin{align*} {\cal L}[e^{at}]s \amp = \int_0^\infty e^{-st} e^{at}\, dt \\ \amp = \int_0^\infty e^{-(s-a)t}\, dt \\ \amp = \frac{1}{s-a}, \end{align*}
    which converges if \(s-a > 0\text{,}\) i.e. \(s > a\text{.}\) Thus:
    🔗
    \begin{equation*} F(s) = \frac{1}{s-a}, \qquad s > a. \end{equation*}
    🔗
    🔗
    11.
    The unit step function is
    🔗
    \begin{equation*} u(t) = \begin{cases} 0 \amp t < 0,\\[4pt] 1 \amp t\ge 0. \end{cases} \end{equation*}
    1. Graph \(u(t)\text{.}\)
      🔗
      🔗
    2. Define \(u_a(t)=u(t-a)\text{.}\) Write it as a piecewise function and graph it.
      🔗
      🔗
    3. Compute \({\cal L}[u_a(t)]\text{.}\)
      🔗
      🔗
    Solution.
    1. Graph: zero for \(t < 0\text{,}\) one for \(t\ge0\text{.}\) A correct sketch shows a step jump at \(t=0\text{.}\)
      🔗
      🔗
    2. Since \(u_a(t)=u(t-a)\text{,}\)
      🔗
      \begin{equation*} u_a(t) = \begin{cases} 0 \amp t < a,\\[4pt] 1 \amp t\ge a. \end{cases} \end{equation*}
      The graph is a horizontal zero line until \(t=a\text{,}\) then jumps to 1.
      🔗
      🔗
    3. Compute:
      🔗
      \begin{align*} {\cal L}[u_a(t)] \amp = \int_a^\infty e^{-st} dt \\ \amp = \frac{e^{-as}}{s}, \qquad s > 0. \end{align*}
      🔗
    🔗
    🔗
    12.
    Compute the inverse Laplace transform of
    🔗
    \begin{equation*} F(s) = \frac{2s-3}{(s-3)(s+2)}. \end{equation*}
    Use partial fractions and tables. Does AI agree with your result?
    🔗
    Solution.
    Write:
    🔗
    \begin{equation*} \frac{2s-3}{(s-3)(s+2)} = \frac{A}{s-3} + \frac{B}{s+2}. \end{equation*}
    Solve:
    🔗
    \begin{equation*} 2s-3 = A(s+2) + B(s-3). \end{equation*}
    Matching coefficients: \(A+B=2\text{,}\) \(2A - 3B = -3\text{.}\)
    🔗
    Solve:
    🔗
    \begin{equation*} A=1,\qquad B=1. \end{equation*}
    Therefore:
    🔗
    \begin{equation*} F(s) = \frac{1}{s-3} + \frac{1}{s+2}. \end{equation*}
    Inverse Laplace:
    🔗
    \begin{equation*} {\cal L}^{-1}[F] = e^{3t} + e^{-2t}. \end{equation*}
    🔗
    🔗
    13.
    Compute the inverse Laplace transform of
    🔗
    \begin{equation*} F(s) = \frac{3}{(s^{2}+4)(s^{2}+9)}. \end{equation*}
    Use partial fractions and tables. Does AI agree with your result?
    🔗
    Solution.
    Use the identity:
    🔗
    \begin{equation*} \frac{1}{(s^2+a^2)(s^2+b^2)} = \frac{1}{b^2-a^2}\! \left( \frac{1}{s^2+a^2} - \frac{1}{s^2+b^2} \right). \end{equation*}
    Here \(a=2\text{,}\) \(b=3\text{,}\) so \(b^2-a^2 = 9-4 = 5\text{.}\)
    🔗
    \begin{align*} F(s) \amp = 3\cdot \frac{1}{5} \left( \frac{1}{s^2+4} - \frac{1}{s^2+9} \right) \\ \amp = \frac{3}{5}\frac{1}{s^2+4} - \frac{3}{5}\frac{1}{s^2+9}. \end{align*}
    Inverse Laplace:
    🔗
    \begin{equation*} {\cal L}^{-1}[1/(s^2+4)] = \frac{1}{2}\sin(2t),\\ {\cal L}^{-1}[1/(s^2+9)] = \frac{1}{3}\sin(3t). \end{equation*}
    Therefore:
    🔗
    \begin{align*} {\cal L}^{-1}[F] \amp = \frac{3}{5}\cdot \frac{1}{2}\sin(2t) - \frac{3}{5}\cdot \frac{1}{3}\sin(3t) \\ \amp = \frac{3}{10}\sin(2t) - \frac{1}{5}\sin(3t). \end{align*}
    🔗
    🔗
    14.
    Use the definition of Laplace transform to compute \({\cal L}[f(t)](s)\) for the function \(f(t)\) graphed in Figure 18.
    🔗
    Solution.
    From the graph:
    🔗
    \begin{equation*} f(t)= \begin{cases} 0, \amp 0\le t < 1,\\ t, \amp t\ge 1. \end{cases} \end{equation*}
    Then:
    🔗
    \begin{align*} {\cal L}[f(t)](s) \amp = \int_{0}^{1} 0\cdot e^{-st}dt + \int_{1}^{\infty} t e^{-st} dt \\ \amp = \int_{1}^{\infty} t e^{-st} dt. \end{align*}
    Compute using integration by parts (or a table):
    🔗
    \begin{equation*} \int t e^{-st}dt = -\frac{t}{s}e^{-st} - \frac{1}{s^2}e^{-st}. \end{equation*}
    Evaluate from 1 to \(\infty\text{:}\)
    🔗
    \begin{equation*} {\cal L}[f(t)](s) = \left[ -\frac{t}{s}e^{-st} - \frac{1}{s^2}e^{-st} \right]_{1}^{\infty} = \frac{1}{s}e^{-s} + \frac{1}{s^2}e^{-s}. \end{equation*}
    So:
    🔗
    \begin{equation*} {\cal L}[f(t)](s) = e^{-s}\left(\frac{1}{s} + \frac{1}{s^{2}}\right),\qquad s > 0. \end{equation*}
    🔗
    🔗
    15.
    Use the definition of Laplace transform to compute \({\cal L}[g(t)](s)\) for the function \(g(t)\) graphed in Figure 19.
    🔗
    Solution.
    From the graph:
    🔗
    \begin{equation*} g(t)= \begin{cases} 0, \amp 0\le t < a,\\ c, \amp a \le t < b,\\ 0, \amp t \ge b. \end{cases} \end{equation*}
    Then:
    🔗
    \begin{align*} {\cal L}[g(t)](s) \amp = \int_{a}^{b} c\, e^{-st}\, dt \\ \amp = c\left[ -\frac{1}{s}e^{-st} \right]_{a}^{b} \\ \amp = \frac{c}{s}\bigl( e^{-as} - e^{-bs}\bigr), \quad s > 0. \end{align*}
    🔗
    🔗
    16.
    Find the inverse Laplace transform of
    🔗
    \begin{equation*} F(s) = \frac{2s}{s^{2}-1}. \end{equation*}
    Solution.
    Factor denominator: \(s^{2}-1 = (s-1)(s+1)\text{.}\) Note:
    🔗
    \begin{align*} \frac{2s}{s^{2}-1} \amp = \frac{2s}{(s-1)(s+1)} \\ \amp = \frac{1}{s-1} + \frac{1}{s+1}. \end{align*}
    Thus:
    🔗
    \begin{equation*} {\cal L}^{-1}[F] = e^{t} + e^{-t}. \end{equation*}
