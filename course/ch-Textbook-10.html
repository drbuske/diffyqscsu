    Handout Daily Prep 2.2 - Constant Coefficient Second Order ODEs
    

    Section Overview

    In this section, we learn how to solve homogeneous second‑order linear differential equations with constant coefficients by assuming exponential solutions and reducing the problem to solving a characteristic quadratic equation. Depending on whether the quadratic has distinct real roots, repeated roots, or complex roots, we will see how each case leads to a different form of the general solution. This method provides a unified and efficient way to analyze many physical systems, setting the stage for deeper exploration of applied models in later sections.
    🔗
    🔗

    Section Basic learning objectives

    These are the tasks you should be able to perform with reasonable fluency when you arrive at our next class meeting. Important new vocabulary words are indicated in italics.
    🔗
    • Recognize when a differential equation is a second‑order linear ODE with constant coefficients.
      🔗
      🔗
    • Use the exponential ansatz \(y=e^{rx}\) to derive the characteristic equation.
      🔗
      🔗
    • Classify solutions according to whether the characteristic equation has distinct real roots, repeated roots, or complex roots.
      🔗
      🔗

    Exercises Exercises

    1. Characteristic Equation.
    What is the characteristic equation associated with the differential equation \(y'' - 6y' + 8y = 0\text{?}\)
    🔗
    • \(r^{2} - 6r + 8 = 0\)
    • Correct. The characteristic equation comes from substituting \(y=e^{rx}\) and dividing by \(e^{rx}\text{.}\)
    • \(r^{2} + 6r + 8 = 0\)
    • Sign error: the coefficient of \(y'\) is \(-6\text{,}\) not \(+6\text{.}\)
    • \(r - 6 + 8 = 0\)
    • This omits the quadratic term required for a second-order equation.
    🔗
    2. Distinct Real Roots.
    The characteristic equation \(r^{2} - 5r + 6 = 0\) has distinct real roots. What is the general solution of the corresponding ODE \(y'' - 5y' + 6y = 0\text{?}\)
    🔗
    • \(y = C_{1} e^{2x} + C_{2} e^{3x}\)
    • Correct. The roots are \(r=2\) and \(r=3\text{.}\) Distinct real roots yield \(y=C_{1}e^{r_{1}x}+C_{2}e^{r_{2}x}\text{.}\)
    • \(y = C_{1}e^{5x} + C_{2}e^{6x}\)
    • Incorrect: those are not the roots of the quadratic.
    • \(y = C_{1}\cos x + C_{2}\sin x\)
    • This form is for complex roots, not real distinct roots.
    🔗
    3. Checking a Proposed Solution.
    Does \(y = e^{4x}\) solve the ODE \(y'' - 8y' + 16y = 0\text{?}\)
    🔗
    • Yes, because \(y'' - 8y' + 16y = (16e^{4x}) - 8(4e^{4x}) + 16e^{4x} = 0\text{.}\)
    • Correct. This ODE corresponds to the characteristic polynomial \((r-4)^{2}=0\text{,}\) whose root \(r=4\) matches \(e^{4x}\text{.}\)
    • No, because \(y'' - 8y' + 16y = 8e^{4x}\text{.}\)
    • Re-check the derivatives and the coefficients.
    • No, because \(e^{4x}\) only solves first-order equations.
    • Incorrect—exponentials are standard solutions for constant-coefficient ODEs.
    🔗
    4. Repeated Root Case.
    If the characteristic equation has a repeated root \(r\text{,}\) what is the correct form of the general solution?
    🔗
    • \(y = C_{1} e^{rx} + C_{2} \, x e^{rx}\)
    • Correct. When the characteristic root is repeated, the second solution is \(x e^{rx}\text{.}\)
    • \(y = C_{1} e^{rx} + C_{2} e^{-rx}\)
    • This form corresponds to distinct real or complex roots, not repeated roots.
    • \(y = C_{1} + C_{2}e^{rx}\)
    • No—this omits the necessary \(x e^{rx}\) term.
    🔗
    5. Solving a Constant-Coefficient ODE.
    Solve the ODE \(y'' + 4y' + 4y = 0\text{.}\)
    🔗
    • \(y = C_{1} e^{-2x} + C_{2} x e^{-2x}\)
    • Correct. The characteristic equation \((r+2)^{2}=0\) has repeated root \(r=-2\text{,}\) so the solution is \(C_{1}e^{-2x} + C_{2} x e^{-2x}\text{.}\)
    • \(y = C_{1}e^{-2x} + C_{2}e^{2x}\)
    • This corresponds to two distinct real roots, which is not the case here.
    • \(y = C_{1}\cos 2x + C_{2}\sin 2x\)
    • This corresponds to complex roots, not a repeated negative real root.
    🔗
    6.
    Consider the IVP
    🔗
    \begin{equation*} y'' - 2y' + 2y = 2x, \qquad y(0)=4, \quad y'(0)=8. \end{equation*}
    1. Show that \(y_p(x) = x + 1\) solves the differential equation.
      🔗
      🔗
    2. Verify that \(y_1(x)=e^{x}\cos x\) and \(y_2(x)=e^{x}\sin x\) solve the associated homogeneous equation.
      🔗
      🔗
    3. Use (a) and (b) to find a solution to the IVP.
      🔗
      🔗
    Solution.
    1. For \(y_p = x+1\text{,}\) we compute:
      🔗
      \begin{equation*} y_p' = 1, y_p'' = 0. \end{equation*}
      Insert into the ODE:
      🔗
      \begin{align*} y_p'' - 2y_p' + 2y_p \amp = 0 - 2(1) + 2(x+1) \\ \amp = -2 + 2x + 2 \\ \amp = 2x. \end{align*}
      Hence \(y_p\) is indeed a particular solution.
      🔗
      🔗
    2. For \(y_1(x)=e^{x}\cos x\text{:}\)
      🔗
      \begin{equation*} y_1' = e^{x}(\cos x - \sin x),\\ y_1'' = e^{x}(\!-2\sin x). \end{equation*}
      Substitute into the homogeneous equation \(y'' - 2y' + 2y = 0\text{:}\)
      🔗
      \begin{align*} y_1'' - 2y_1' + 2y_1 \amp = e^{x}(-2\sin x) - 2e^{x}(\cos x - \sin x) + 2e^{x}\cos x \\ \amp = 0. \end{align*}
      For \(y_2(x)=e^{x}\sin x\text{:}\)
      🔗
      \begin{equation*} y_2' = e^{x}(\sin x + \cos x),\\ y_2'' = e^{x}(2\cos x). \end{equation*}
      Substitute:
      🔗
      \begin{align*} y_2'' - 2y_2' + 2y_2 \amp = e^{x}(2\cos x) - 2e^{x}(\sin x + \cos x) + 2e^{x}\sin x \\ \amp = 0. \end{align*}
      Thus both \(y_1\) and \(y_2\) solve the homogeneous equation.
      🔗
      🔗
    3. The general solution is:
      🔗
      \begin{align*} y(x) \amp = y_p(x) + C_1 y_1(x) + C_2 y_2(x) \\ \amp = (x+1) + C_1 e^{x}\cos x + C_2 e^{x}\sin x. \end{align*}
      Apply the initial conditions.
      🔗
      First:
      🔗
      \begin{equation*} y(0) = 1 + C_1 = 4 \quad\Rightarrow\quad C_1 = 3. \end{equation*}
      Next compute \(y'\text{:}\)
      🔗
      \begin{equation*} y' = 1 + C_1 e^{x}(\cos x - \sin x) + C_2 e^{x}(\sin x + \cos x). \end{equation*}
      Evaluate at \(x=0\text{:}\)
      🔗
      \begin{equation*} y'(0) = 1 + C_1 + C_2 = 8. \end{equation*}
      Using \(C_1=3\) gives:
      🔗
      \begin{equation*} 1 + 3 + C_2 = 8 \quad\Longrightarrow\quad C_2 = 4. \end{equation*}
      Therefore, the solution to the IVP is:
      🔗
      \begin{equation*} y(x) = x + 1 + 3 e^{x}\cos x + 4 e^{x}\sin x. \end{equation*}
      🔗
    🔗
    🔗
    7.
    Find the general solution to the differential equation
    \begin{equation*} y'' + 6y' + 13y = 0. \end{equation*}
    🔗
    Solution.
    The characteristic equation is
    🔗
    \begin{equation*} r^{2} + 6r + 13 = 0. \end{equation*}
    Thus the roots are
    🔗
    \begin{equation*} r = \frac{-6 \pm \sqrt{-16}}{2} = -3 \pm 2i. \end{equation*}
    So the general solution is
    🔗
    \begin{equation*} y(x) = e^{-3x}\bigl(C_1 \cos 2x + C_2 \sin 2x\bigr). \end{equation*}
    🔗
    🔗
    8.
    Construct a differential equation whose general solution is
    \begin{equation*} y = C_{1} e^{-2x}\cos(3x) \;+\; C_{2} e^{-2x}\sin(3x). \end{equation*}
    🔗
    Solution.
    This solution corresponds to characteristic roots \(r = -2 \pm 3i\text{.}\)
    🔗
    Therefore the characteristic equation is
    🔗
    \begin{equation*} (r + 2 - 3i)(r + 2 + 3i) = (r + 2)^{2} + 9 = r^{2} + 4r + 13. \end{equation*}
    Hence the corresponding differential equation is
    🔗
    \begin{equation*} y'' + 4y' + 13y = 0. \end{equation*}
    🔗
    🔗
    🔗
