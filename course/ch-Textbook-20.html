    Handout Daily Prep 4.3 - Elimination
    

    Section Overview

    In this section we learn how systems of linear equations can be solved systematically using elimination, a method that rewrites equations in ways that preserve their solutions. You will see how a system can be expressed compactly as a matrix equation\(A \vec{x}= \vec{b}\text{,}\) why elimination helps even when the matrix is not invertible or not square, and how a small set of simple operations— swapping equations, scaling equations, and adding multiples of one equation to another— can always be used to reduce a system to a form where solutions can be read off directly. These ideas also motivate the construction of the augmented matrix, which provides a compact way to organize the elimination process and serves as the starting point for many linear-algebra algorithms.
    🔗
    🔗

    Exercises Exercises

    1. Meaning of an Elementary Row Operation.
    Which of the following is an elementary row operation used in elimination?
    🔗
    • Replacing a row by that row plus a multiple of another row.
    • Correct — this is one of the three fundamental row operations.
    • Multiplying two rows together.
    • No — row multiplication is not allowed.
    • Raising a row to a power.
    • No — this has nothing to do with row operations.
    🔗
    2. First Step of Elimination.
    Consider the system represented by the augmented matrix
    \begin{equation*} \left[\begin{array}{cc|c} 2 \amp 1 \amp 5\\ 4 \amp -2 \amp 6 \end{array}\right]. \end{equation*}
    What is a valid first elimination step?
    🔗
    • Replace Row 2 with Row 2 − 2·Row 1.
    • Correct — this eliminates the \(4\) beneath the leading \(2\text{.}\)
    • Replace Row 1 with Row 1 × Row 2.
    • No — rows may not be multiplied together.
    • Replace Row 1 with Row 1 + Row 1.
    • No — that does not help eliminate any entry.
    🔗
    3. Pivot Identification.
    In the row‑echelon matrix
    \begin{equation*} \begin{bmatrix} 1 \amp 3 \amp 2\\ 0 \amp 1 \amp -5\\ 0 \amp 0 \amp 7 \end{bmatrix}, \end{equation*}
    where are the pivots located?
    🔗
    • The entries 1, 1, and 7 on the diagonal.
    • Correct — these are the first nonzero entries of each row.
    • The entries 3, 1, and −5.
    • No — those are not the first nonzero entries of their rows.
    • The entries 2, −5, and 7.
    • No — not all of these are pivots.
    🔗
    4. Meaning of a Row Swap.
    Why might one perform a row swap during elimination?
    🔗
    • To move a nonzero entry into a pivot position.
    • Correct — swapping helps ensure each pivot is nonzero.
    • To change the solution set of the system.
    • No — row operations must preserve the solution set.
    • To make the matrix symmetric.
    • No — symmetry is not relevant to elimination.
    🔗
    5. Interpreting an Inconsistent System.
    After performing elimination, you obtain the augmented row
    \begin{equation*} \begin{bmatrix}0 \amp 0 \amp 0 \amp | \amp 5\end{bmatrix}. \end{equation*}
    What does this indicate?
    🔗
    • The system is inconsistent and has no solution.
    • Correct — the equation \(0=5\) cannot be satisfied.
    • There are infinitely many solutions.
    • No — that would arise from a row of all zeros including the augmented entry.
    • There is exactly one solution.
    • No — contradiction rows mean no solution.
    🔗
    6. Back‑Substitution Step.
    After elimination, a system is reduced to:
    \begin{equation*} \begin{aligned} x + 2y \amp= 5,\\ y \amp= 1. \end{aligned} \end{equation*}
    What is the value of \(x\text{?}\)
    🔗
    • \(x = 3\)
    • Correct — substitute \(y=1\) into \(x+2y=5\text{.}\)
    • \(x = 2\)
    • No — substitution gives \(x=5-2=3\text{.}\)
    • \(x = -1\)
    • No — that would satisfy \(x+2=5\) incorrectly.
    🔗
    7. Meaning of Matrix Rank.
    What is the rank of a matrix?
    🔗
    • The number of pivot columns in its row‑echelon form.
    • Correct — rank equals the number of leading 1s, which is also the dimension of the column space.
    • The number of nonzero rows before row reduction.
    • No — rank must be computed after row reduction, not before.
    • The number of columns of the matrix.
    • No — only pivot columns count.
    🔗
    8. Interpreting Span.
    Let \(\vec{v}_1, \vec{v}_2\) be vectors in \(\mathbb{R}^3\text{.}\) What does \(\operatorname{span}\{\vec{v}_1,\vec{v}_2\}\) represent?
    🔗
    • The set of all linear combinations of \(\vec{v}_1\) and \(\vec{v}_2\text{.}\)
    • Correct — span is defined as all linear combinations.
    • Only the vectors \(\vec{v}_1\) and \(\vec{v}_2\) themselves.
    • No — the span contains infinitely many vectors.
    • The set of all vectors perpendicular to \(\vec{v}_1\) and \(\vec{v}_2\text{.}\)
    • No — that describes the orthogonal complement, not the span.
    🔗
    9. Rank and Solutions.
    For a system \(A\vec{x}=\vec{b}\text{,}\) when is the system consistent?
    🔗
    • The system is consistent exactly when \(\operatorname{rank}(A)=\operatorname{rank}([A\mid \vec{b}])\text{.}\)
    • Correct — equality of ranks is the standard consistency criterion.
    • When \(A\) has at least one pivot in every row.
    • No — what matters is comparing the two ranks, not pivot count alone.
    • When \(\vec{b}=\vec{0}\text{.}\)
    • No — homogeneous systems are always consistent, but this is not the general criterion.
    🔗

      If possible, match each linear system on the left to its corresponding augmented matrix. Not all systems may be used.

    11.
    List the three elementary row operations. What do these row operations preserve?
    🔗
    Solution.
    The three elementary row operations are:
    🔗
    • Swap two rows.
      🔗
    • Multiply a row by a nonzero scalar.
      🔗
    • Replace a row by itself plus a multiple of another row.
      🔗
    These operations preserve the solution set of the linear system. That is, performing any sequence of these operations does not change the set of solutions.
    🔗
    🔗
    🔗
    12.
    If a linear system has a free variable, what does that tell you about the solution space?
    🔗
    Solution.
    A free variable means the system has infinitely many solutions. Free variables correspond to directions in which the solution can vary, giving a solution space that forms a line, plane, or higher-dimensional affine subset.
    🔗
    🔗
    🔗
    13.
    Is this system consistent? If so, why? If not, why not?
    🔗
    \begin{align*} x_1 - 2x_2 + x_3 \amp = 0 \\ 2x_2 - 8x_3 \amp = 8 \\ -4x_1 + 5x_2 + 9x_3 \amp = -9 \end{align*}
    This system reduces to:
    🔗
    \begin{align*} x_1 - 2x_2 + x_3 \amp = 0 \\ x_2 - 4x_3 \amp = 4 \\ x_3 \amp = 3 \end{align*}
    The augmented matrix is:
    🔗
    \begin{equation*} \left[ \begin{array}{ccc|c} 1 \amp -2 \amp 1 \amp 0\\ 0 \amp 1 \amp -4 \amp 4\\ 0 \amp 0 \amp 3 \amp 3 \end{array} \right] \end{equation*}
    Solution.
    The system is consistent because no row reduces to a contradiction of the form \([0\ 0\ 0\ |\ c]\) with \(c\neq 0\text{.}\) The last equation \(3x_3 = 3\) is solvable (\(x_3 = 1\)), and the others follow.
    🔗
    🔗
    🔗
    14.
    Determine if the system is consistent. If so, why? If not, why not?
    🔗
    \begin{align*} 3x_2 - 6x_3 \amp = 8 \\ x_1 - 2x_2 + 3x_3 \amp = -1 \\ 5x_1 - 7x_2 + 9x_3 \amp = 0 \end{align*}
    Row reduction gives:
    🔗
    \begin{align*} \left[ \begin{array}{ccc|c} 0 \amp 3 \amp -6 \amp 8\\ 1 \amp -2 \amp 3 \amp -1\\ 5 \amp -7 \amp 9 \amp 0 \end{array} \right] \amp \sim \left[ \begin{array}{ccc|c} 1 \amp -2 \amp 3 \amp -1\\ 0 \amp 3 \amp -6 \amp 8\\ 0 \amp 3 \amp -6 \amp 5 \end{array} \right] \\ \amp \sim \left[ \begin{array}{ccc|c} 1 \amp -2 \amp 3 \amp -1\\ 0 \amp 3 \amp -6 \amp 8\\ 0 \amp 0 \amp 0 \amp -3 \end{array} \right] \end{align*}
    Solution.
    The last row corresponds to \(0 = -3\text{,}\) a contradiction. Therefore, the system is inconsistent and has no solution.
    🔗
    🔗
    🔗
    15.
    Let \(A=\begin{bmatrix}1 \amp 2\\[4pt] 3 \amp 1\\[4pt] 0 \amp 5\end{bmatrix}\) and \(\vec{b}=\begin{bmatrix}8\\3\\17\end{bmatrix}\text{.}\) We want to determine whether \(\vec{b}\) lies in the plane spanned by the columns of \(A\text{.}\)
    🔗
    1. Finish rewriting this question in vector form: “Do weights \(x_1\) and \(x_2\) exist so that …?”
      🔗
      🔗
    2. The augmented matrix row‑reduces as follows:
      🔗
      \begin{align*} \left[ \begin{array}{cc|c} 1 \amp 2 \amp 8\\ 3 \amp 1 \amp 3\\ 0 \amp 5 \amp 17 \end{array} \right] \amp \sim \left[ \begin{array}{cc|c} 1 \amp 2 \amp 8\\ 0 \amp -5 \amp -21\\ 0 \amp 5 \amp 17 \end{array} \right] \\ \amp \sim \left[ \begin{array}{cc|c} 1 \amp 2 \amp 8\\ 0 \amp -5 \amp -21\\ 0 \amp 0 \amp -4 \end{array} \right]. \end{align*}
      Is \(\vec{b}\) in the plane spanned by the columns of \(A\text{?}\)
      🔗
      🔗
    Solution.
    (a) The vector‑form question is:
    🔗
    \begin{equation*} \text{Do there exist }x_1,x_2\text{ such that } x_1\begin{bmatrix}1\\3\\0\end{bmatrix} + x_2\begin{bmatrix}2\\1\\5\end{bmatrix} = \begin{bmatrix}8\\3\\17\end{bmatrix} ? \end{equation*}
    (b) The final row of the REF matrix is:
    🔗
    \begin{equation*} \left[0\ \ 0\ \ |\ -4\right], \end{equation*}
    which corresponds to the equation \(0=-4\text{,}\) a contradiction. Therefore the system has **no solution**, and
    🔗
    \begin{equation*} \vec{b} \text{ is NOT in } \operatorname{span}\{ \text{columns of }A\}. \end{equation*}
    🔗
    🔗
    16.
    Consider the augmented matrix:
    🔗
    \begin{equation*} \left[ \begin{array}{ccc|c} 2 \amp 3 \amp 4 \amp 9\\ -3 \amp 1 \amp 0 \amp -2 \end{array} \right]. \end{equation*}
    1. Write the corresponding system of equations.
      🔗
      🔗
    2. Fill in the missing coefficients in the vector equation:
      🔗
      \begin{equation*} x_1\begin{bmatrix}2\\-3\end{bmatrix} \;+\; x_2\begin{bmatrix}3\\1\end{bmatrix} \;+\; x_3\begin{bmatrix}4\\0\end{bmatrix} \;=\; \begin{bmatrix}9\\-2\end{bmatrix}. \end{equation*}
      🔗
    3. Write this in the form \(A\vec{x}=\vec{b}\text{.}\)
      🔗
      🔗
    Solution.
    (a) System of equations:
    🔗
    \begin{align*} 2x_1 + 3x_2 + 4x_3 \amp = 9\\ -3x_1 + 1x_2 + 0x_3 \amp = -2 \end{align*}
    (b) The completed vector equation already appears correct (no blanks remain).
    🔗
    (c) Matrix equation:
    🔗
    \begin{equation*} \begin{bmatrix} 2 \amp 3 \amp 4\\ -3 \amp 1 \amp 0 \end{bmatrix} \begin{bmatrix} x_1\\x_2\\x_3 \end{bmatrix} = \begin{bmatrix} 9\\-2 \end{bmatrix}. \end{equation*}
    🔗
    🔗
    17.
    The equation \(A\vec{x}=\vec{b}\) has a solution if and only if \(\vec{b}\) is a of the columns of \(A\text{.}\)
    🔗
    Solution.
    The correct phrase is:
    🔗
    \begin{equation*} \vec{b}\text{ is a linear combination of the columns of }A. \end{equation*}
    Thus the filled‑in blanks are: linear and combination.
    🔗
    🔗
    🔗
    18.
    Use the inverse of \(A=\begin{bmatrix}-7 \amp 3\\ 5 \amp -2\end{bmatrix}\) to solve:
    🔗
    \begin{align*} -7x_1 + 3x_2 \amp = 2 \\ 5x_1 - 2x_2 \amp = 1 \end{align*}
    Solution.
    1. Compute the inverse.
    🔗
    For \(A=\begin{bmatrix}a \amp b\\ c \amp d\end{bmatrix}\text{,}\) \(A^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d \amp -b\\ -c \amp a\end{bmatrix}\text{.}\)
    🔗
    Here \(a=-7\text{,}\) \(b=3\text{,}\) \(c=5\text{,}\) \(d=-2\text{.}\)
    🔗
    \begin{equation*} ad-bc = (-7)(-2) - (3)(5) = 14 - 15 = -1. \end{equation*}
    \begin{equation*} A^{-1} = -1^{-1} \begin{bmatrix} -2 \amp -3\\ -5 \amp -7 \end{bmatrix} = \begin{bmatrix} 2 \amp 3\\ 5 \amp 7 \end{bmatrix}. \end{equation*}
    2. Compute \(\vec{x}=A^{-1}\vec{b}\text{.}\)
    🔗
    \begin{equation*} \vec{b}=\begin{bmatrix}2\\1\end{bmatrix}, \qquad \vec{x} = \begin{bmatrix} 2 \amp 3\\ 5 \amp 7 \end{bmatrix} \begin{bmatrix} 2\\1 \end{bmatrix} = \begin{bmatrix} 2\cdot 2 + 3\cdot 1\\ 5\cdot 2 + 7\cdot 1 \end{bmatrix} = \begin{bmatrix} 7\\17 \end{bmatrix}. \end{equation*}
    Thus the solution is \(x_1=7,\; x_2=17\text{.}\)

    19.
    Use the augmented matrix below to determine the inverse of \(A=\begin{bmatrix}2 \amp 0 \amp 0\\ -3 \amp 0 \amp 1\\ 0 \amp 1 \amp 0\end{bmatrix}\text{,}\) if it exists.
    🔗
    \begin{equation*} \left[ \begin{array}{ccc|ccc} 2 \amp 0 \amp 0 \amp 1 \amp 0 \amp 0\\ -3 \amp 0 \amp 1 \amp 0 \amp 1 \amp 0\\ 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 1 \end{array} \right] \sim \dots \sim \left[ \begin{array}{ccc|ccc} 1 \amp 0 \amp 0 \amp \tfrac12 \amp 0 \amp 0\\ 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 1\\ 0 \amp 0 \amp 1 \amp \tfrac12 \amp 1 \amp 0 \end{array} \right] \end{equation*}
    Solution.
    The final augmented matrix has the form \([I\mid A^{-1}]\text{.}\) Therefore:
    🔗
    \begin{equation*} A^{-1} = \begin{bmatrix} \tfrac12 \amp 0 \amp 0\\ 0 \amp 0 \amp 1\\ \tfrac12 \amp 1 \amp 0 \end{bmatrix}. \end{equation*}
    Since we completed the reduction successfully, \(A\) is invertible.

    20.
    Compute the rank of \(A=\begin{bmatrix} 1 \amp 2 \amp 3\\ 2 \amp 4 \amp 6\\ 1 \amp 1 \amp 0 \end{bmatrix} \text{.}\) Then describe \(\operatorname{span}\{\text{columns of }A\}\text{.}\)
    🔗
    Solution.
    Row‑reduce:
    🔗
    \begin{align*} \begin{bmatrix} 1 \amp 2 \amp 3\\ 2 \amp 4 \amp 6\\ 1 \amp 1 \amp 0 \end{bmatrix} \amp \sim \begin{bmatrix} 1 \amp 2 \amp 3\\ 0 \amp 0 \amp 0\\ 0 \amp -1 \amp -3 \end{bmatrix} \\ \amp \sim \begin{bmatrix} 1 \amp 2 \amp 3\\ 0 \amp 1 \amp 3\\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{align*}
    There are 2 pivot columns, so \(\operatorname{rank}(A)=2\text{.}\)
    🔗
    Thus the columns of \(A\) span a 2‑dimensional plane in \(\mathbb{R}^3\text{.}\)

    21.
    Let \(\vec{u}=\begin{bmatrix}1\\2\\1\end{bmatrix}\text{,}\) \(\vec{v}=\begin{bmatrix}-1\\1\\0\end{bmatrix}\text{,}\) and \(\vec{w}=\begin{bmatrix}3\\3\\2\end{bmatrix}\text{.}\) Determine whether \(\vec{w}\) is in \(\operatorname{span}\{\vec{u},\vec{v}\}\text{.}\)
    🔗
    Solution.
    Solve \(a\vec{u} + b\vec{v} = \vec{w}\text{:}\)
    🔗
    \begin{equation*} a\begin{bmatrix}1\\2\\1\end{bmatrix} + b\begin{bmatrix}-1\\1\\0\end{bmatrix} = \begin{bmatrix}3\\3\\2\end{bmatrix}. \end{equation*}
    Component equations:
    🔗
    \begin{align*} a - b \amp = 3\\ 2a + b \amp = 3\\ a \amp = 2 \end{align*}
    From the third equation, \(a=2\text{.}\) Substitute into the first: \(2 - b = 3\) → \(b=-1\text{.}\) Check the second:
    🔗
    \begin{equation*} 2(2) + (-1) = 3 \quad \text{✓} \end{equation*}
    Therefore \(\vec{w} = 2\vec{u} - \vec{v}\text{,}\) so \(\vec{w}\) is in the span.
