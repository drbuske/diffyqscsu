    Exercises Sample Questions

    1. Invertibility of a Matrix.
    The matrix \(A = \begin{pmatrix} 0 \amp 1 \\ 1 \amp 1 \end{pmatrix}\) is invertible.
    🔗
    • True.
    • Correct. The determinant is \(\det(A) = -1 \neq 0\text{,}\) so the matrix is invertible.
    • False.
    • No. The matrix has nonzero determinant, so it is invertible.
    🔗
    2. Difference of Eigenvectors.
    The difference of two eigenvectors \(\mathbf{v}_1\) and \(\mathbf{v}_2\) of a matrix \(A\) is always an eigenvector of \(A\text{.}\)
    🔗
    • True.
    • No. Only scalar multiples of a single eigenvector are guaranteed to remain eigenvectors.
    • False.
    • Correct. The difference of eigenvectors corresponding to the same eigenvalue is an eigenvector, but this fails for eigenvectors from different eigenvalues.
    🔗
    3. Diagonalizability of a Matrix and its Square.
    If a \(2 \times 2\) matrix \(A\) is diagonalizable, then \(A^2\) is diagonalizable.
    🔗
    • True.
    • Correct. If \(A = PDP^{-1}\text{,}\) then \(A^2 = PD^2P^{-1}\text{,}\) which is also diagonalizable.
    • False.
    • No. The diagonalizability of \(A\) guarantees the same for \(A^2\text{.}\)
    🔗
    4. Geometric vs. Algebraic Multiplicity.
    In an \(n \times n\) matrix \(A\text{,}\) the geometric multiplicity of each eigenvalue is less than or equal to its algebraic multiplicity.
    🔗
    • True.
    • Correct. This is a fundamental theorem of eigenstructure: \(1 \le \text{geom mult} \le \text{alg mult}\text{.}\)
    • False.
    • No. Geometric multiplicity can never exceed algebraic multiplicity.
    🔗
    5. Solutions to a Linear System.
    For a \(20 \times 10\) matrix \(A\text{,}\) the equation \(A\mathbf{x}=\mathbf{b}\) has either zero or infinitely many solutions.
    🔗
    • True.
    • No. Such a system can have exactly one solution if consistent and full column rank.
    • False.
    • Correct. A tall matrix \(A\) (more equations than unknowns) can have zero, one, or infinitely many solutions.
    🔗
    6. Diagonalizability over \(\mathbb{R}\) vs. \(\mathbb{C}\).
    There exist matrices which are diagonalizable over the complex numbers but not over the real numbers.
    🔗
    • True.
    • Correct. For example, a rotation matrix in \(\mathbb{R}^2\) has complex eigenvalues but no real eigenvalues.
    • False.
    • No. Complex diagonalizability does not guarantee real diagonalizability.
    🔗
    7. Boundedness of Differential Equation Solutions.
    For the differential equation \(x''(t) + x(t) = \sin t\text{,}\) all solutions are bounded.
    🔗
    • True.
    • No. The forcing term \(\sin t\) resonates with the homogeneous solution.
    • False.
    • Correct. There exist unbounded solutions due to resonance: the particular solution contains a term linear in \(t\text{.}\)
    🔗
    8. Similarity and Transposes.
    If a \(2\times 2\) matrix \(A\) is similar to a matrix \(B\text{,}\) then the transpose \(A^T\) is similar to \(B^T\text{.}\)
    🔗
    • True.
    • Correct. If \(A = PBP^{-1}\text{,}\) then \(A^T = (P^{-1})^T B^T P^T\text{,}\) showing similarity.
    • False.
    • No. Transposition preserves similarity.
    🔗
    9. Eigenvalues and Invertibility.
    A \(3\times 3\) matrix \(A\) is invertible if and only if all its eigenvalues are positive.
    🔗
    • True.
    • No. Invertibility requires eigenvalues to be nonzero, not necessarily positive.
    • False.
    • Correct. A matrix with eigenvalues \(-2, 3, -1\) is invertible but not all positive.
    🔗
    10. Subspace Defined by Inequalities.
    The set of vectors \(\begin{pmatrix} x_1 \\ x_2 \end{pmatrix}\) in \(\mathbb{R}^2\) satisfying \(x_1 \ge 2x_2\) and \(\frac12 x_1 \le x_2\) is a subspace.
    🔗
    • True.
    • Correct. The two inequalities together force \(x_1 = 2x_2\text{,}\) describing a line through the origin — a subspace.
    • False.
    • No. The set actually forms a one-dimensional subspace.
    🔗
    11. Similarity and Eigenvalues.
    Suppose \(A = \begin{pmatrix} 1 \amp 1 \\ 0 \amp -1 \end{pmatrix},\quad B = \begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix},\quad C = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 0 \end{pmatrix},\quad D = \begin{pmatrix} 1 \amp 1 \\ 1 \amp 1 \end{pmatrix},\quad E = \begin{pmatrix} -1 \amp 1 \\ 0 \amp 1 \end{pmatrix}.\) Which matrices have the same eigenvalues and are similar?
    🔗
    Hint.
    Similar matrices must have exactly the same eigenvalues, including multiplicities. Compute the eigenvalues of each matrix and compare them.
    🔗
    🔗
    Answer.
    \(B\text{,}\) \(A\text{,}\) and \(E\) have the same eigenvalues and are similar to each other. Also, \(C\) and \(D\) have the same eigenvalues and are similar.
    🔗
    🔗
    Solution.
    We compute eigenvalues one matrix at a time:
    🔗
    • \(A\) has eigenvalues \(1\) and \(-1\text{.}\)
      🔗
      🔗
    • \(B\) has eigenvalues \(-1\) and \(1\text{.}\)
      🔗
      🔗
    • \(E\) also has eigenvalues \(-1\) and \(1\text{.}\)
      🔗
      🔗
    • \(C\) has eigenvalues \(2\) and \(0\text{.}\)
      🔗
      🔗
    • \(D\) has eigenvalues \(2\) and \(0\text{.}\)
      🔗
      🔗
    Matrices that are similar must have exactly the same eigenvalues with the same multiplicities. So:
    🔗
    • \(A\text{,}\) \(B\text{,}\) and \(E\) share the same two eigenvalues \(1\) and \(-1\text{.}\) Therefore, they are similar to one another.
      🔗
      🔗
    • \(C\) and \(D\) both have eigenvalues \(2\) and \(0\text{.}\) Thus, they are similar to each other as well.
      🔗

    2. \(\displaystyle \mathbf{x}' = \begin{pmatrix} 0 \amp 0 \\ 0 \amp 1 \end{pmatrix} \mathbf{x}\)

    3. \(\displaystyle \mathbf{x}' = \begin{pmatrix} 2 \amp 2 \\ 0 \amp -2 \end{pmatrix} \mathbf{x}\)

    13. Solving a Linear System and Describing Its Solution Set.
    Consider the linear system
    🔗
    \(\begin{aligned} x_1 + 2x_2 + 3x_3 + 3x_4 + 2x_5 + x_6 \amp = 3,\\ \quad x_2 + 2x_3 + 2x_4 + x_5 \amp = 2,\\ \quad x_3 + x_4 \amp = 1. \end{aligned}\)
    🔗
    Answer the following:
    🔗
    1. Rewrite the system in matrix form \(A\mathbf{x}=\mathbf{b}\text{.}\)
      🔗
    2. Row reduce the augmented matrix \([A \mid \mathbf{b}]\text{.}\)
      🔗
    3. Find the general solution to the system.
      🔗
    4. Determine whether the solution set is a subspace of \(\mathbb{R}^6\text{.}\) If it is, state its dimension; if not, explain why not.
      🔗
    Hint.
    Start by assembling the coefficient matrix \(A\) and vector \(\mathbf{b}\text{.}\) After forming the augmented matrix, perform row reduction carefully. Identify pivot and free variables before expressing the general solution.
    🔗
    🔗
    Answer.
    The system can be written as \(A\mathbf{x}=\mathbf{b}\) with \(A = \begin{pmatrix} 1 \amp 2 \amp 3 \amp 3 \amp 2 \amp 1\\ 1 \amp 1 \amp 2 \amp 2 \amp 1 \amp 1\\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \end{pmatrix}, \quad \mathbf{b}= \begin{pmatrix} 3\\2\\1 \end{pmatrix}.\)
    🔗
    After row reduction: \(\left[ \begin{array}{cccccc|c} 1 \amp 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 0\\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \end{array} \right].\)
    🔗
    A general solution is: \(\mathbf{x} = \begin{pmatrix} 0\\0\\1\\0\\0\\0 \end{pmatrix} + x_4\begin{pmatrix} 0\\0\\-1\\1\\0\\0 \end{pmatrix} + x_5\begin{pmatrix} 0\\-1\\0\\0\\1\\0 \end{pmatrix} + x_6\begin{pmatrix} -1\\0\\0\\0\\0\\1 \end{pmatrix}.\)
    🔗
    The solution set is not a subspace of \(\mathbb{R}^6\text{,}\) because it does not contain the zero vector.
    🔗
    🔗
    Solution.
    From the coefficients, we obtain:
    🔗
    \(A = \begin{pmatrix} 1 \amp 2 \amp 3 \amp 3 \amp 2 \amp 1\\ 1 \amp 1 \amp 2 \amp 2 \amp 1 \amp 1\\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \end{pmatrix}, \qquad \mathbf{b}= \begin{pmatrix} 3\\2\\1 \end{pmatrix}.\)
    🔗
    The augmented matrix is \(\left[ \begin{array}{cccccc|c} 1 \amp 2 \amp 3 \amp 3 \amp 2 \amp 1 \amp 3\\ 1 \amp 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2\\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \end{array} \right].\) After row reduction: \(\left[ \begin{array}{cccccc|c} 1 \amp 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 0\\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \amp 0 \amp 1 \end{array} \right].\)
    🔗
    The pivot variables are \(x_1\text{,}\) \(x_2\text{,}\) and \(x_3\text{.}\) The free variables are \(x_4\text{,}\) \(x_5\text{,}\) and \(x_6\text{.}\) Solving gives:
    🔗
    \(\mathbf{x} = \begin{pmatrix} 0\\0\\1\\0\\0\\0 \end{pmatrix} + x_4\begin{pmatrix} 0\\0\\-1\\1\\0\\0 \end{pmatrix} + x_5\begin{pmatrix} 0\\-1\\0\\0\\1\\0 \end{pmatrix} + x_6\begin{pmatrix} -1\\0\\0\\0\\0\\1 \end{pmatrix}.\)
    🔗
    Because the solution set does not include the zero vector (the particular solution has a nonzero entry), it is not closed under scalar multiplication. Therefore, the set of solutions is not a subspace of \(\mathbb{R}^6\text{.}\)

    14. Newton’s Law of Cooling.
    Newton’s law of cooling states that the time rate of change of the temperature \(T(t)\) of a body immersed in a medium of constant temperature \(A\) is proportional to the difference \(A - T\text{,}\) that is,
    \begin{equation*} \dfrac{dT}{dt} = k(A - T). \end{equation*}
    🔗
    A cake is removed from an oven at \(210^\circ\!F\) and left to cool in a room with ambient temperature \(70^\circ\!F\text{.}\) After 30 minutes the cake’s temperature is \(140^\circ\!F\text{.}\) When will the temperature reach \(100^\circ\!F\text{?}\)
    🔗
    Hint.
    Solve the differential equation to obtain \(T(t) = A + (T_0 - A)e^{-kt}\text{.}\) Use the known temperature at \(t=30\) to compute \(k\text{,}\) then solve \(T(t)=100\) for \(t\text{.}\)
    🔗
    🔗
    Answer.
    The cake reaches \(100^\circ\!F\) after approximately \(66.7\) minutes (about 66 minutes and 40 seconds).
    🔗
    🔗
    Solution.
    The general solution to Newton’s cooling equation is \(T(t) = A + (T_0 - A)e^{-kt}.\) Using \(A = 70\) and \(T_0 = 210\text{,}\) we obtain \(T(t) = 70 + 140e^{-kt}.\)
    🔗
    We know that \(T(30) = 140\text{,}\) so: \(140 = 70 + 140e^{-30k} \quad\Longrightarrow\quad 70 = 140e^{-30k} \quad\Longrightarrow\quad \tfrac12 = e^{-30k}.\)
    🔗
    Taking natural logarithms, \(-30k = \ln\!\left(\tfrac12\right) = -\ln 2, \quad\text{so}\quad k = \frac{\ln 2}{30}.\)
    🔗
    Now solve for \(t\) when \(T(t)=100\text{:}\) \(100 = 70 + 140e^{-kt} \quad\Longrightarrow\quad 30 = 140e^{-kt} \quad\Longrightarrow\quad \tfrac{3}{14} = e^{-kt}.\)
    🔗
    Taking logarithms again, \(-kt = \ln\!\left(\tfrac{3}{14}\right), \quad\Longrightarrow\quad t = \frac{-\ln(\frac{3}{14})}{k} = \frac{-\ln(\frac{3}{14})}{\ln 2 / 30}.\)
    🔗
    Numerically, \(-\ln\!\left(\tfrac{3}{14}\right) \approx 1.540445, \qquad k \approx 0.0231049,\) giving \(t \approx \frac{1.540445}{0.0231049} \approx 66.7\ \text{minutes}.\)
    🔗
    Therefore, the cake cools to \(100^\circ\!F\) after approximately \(66\) minutes and \(40\) seconds.

    48. Autonomous Differential Equation and Equilibria.
    Consider the differential equation
    \begin{equation*} \dfrac{dx}{dt} = k(N - x)(x - H), \end{equation*}
    where \(k > 0\) and \(H < N\) are constants. Determine whether this DE is autonomous. If it is, find all equilibrium solutions and classify each as stable or unstable.
    🔗
    Hint.
    A differential equation is autonomous if the right-hand side depends only on \(x\) and constants, not on \(t\text{.}\) Equilibria occur where \(dx/dt = 0\text{.}\) Use a sign chart on \(k(N-x)(x-H)\) to determine stability.
    🔗
    🔗
    Answer.
    The DE is autonomous. The equilibrium solutions are \(x = H\) and \(x = N\text{.}\) \(x = H\) is unstable, and \(x = N\) is stable.
    🔗
    🔗
    Solution.
    The right-hand side of the DE, \(f(x) = k(N - x)(x - H),\) depends only on \(x\) (and constants), not on \(t\text{,}\) so the equation is autonomous.
    🔗
    Equilibria occur where \(dx/dt = 0\text{.}\) Thus, \(k(N - x)(x - H) = 0\) implies \(x = H\) or \(x = N\text{.}\)
    🔗
    To classify the equilibria, examine the sign of \(f(x)\) on the intervals determined by \(H\) and \(N\text{.}\) Because \(k > 0\text{,}\) the sign of \(dx/dt\) is the sign of \((N - x)(x - H)\text{.}\)
    🔗
    • For \(x < H\text{,}\) \(N - x > 0\) and \(x - H < 0\text{,}\) so \(dx/dt < 0\text{.}\) Solutions move left, away from \(x = H\text{.}\)
      🔗
    • For \(H < x < N\text{,}\) both \(N - x\) and \(x - H\) are positive, so \(dx/dt > 0\text{.}\) Solutions move right, again away from \(x = H\text{.}\)
      🔗

      🔗
    • For \(H < x < N\text{,}\) \(dx/dt > 0\text{,}\) so solutions move right, again toward \(x = N\text{.}\)
      🔗
    Thus \(x = N\) is stable.
    🔗
    Therefore, the equation is autonomous, with equilibrium solutions \(x = H\) (unstable) and \(x = N\) (stable).

    Use the eigenvalue–eigenvector method to find a general solution to the system
    🔗

    Is the equilibrium solution \(x_1(t)\equiv 0\text{,}\) \(x_2(t)\equiv 0\) stable or not?
    🔗
    Hint.
    Write the system in matrix form \(\mathbf{x}' = A\mathbf{x}\) and compute the eigenvalues of \(A\text{.}\) Distinct real eigenvalues give independent eigenvectors, and the sign of each eigenvalue determines stability of the origin.
    🔗
    🔗
    Answer.
    The eigenvalues are \(\lambda_1 = 3\) and \(\lambda_2 = -1\text{,}\) with eigenvectors \(\left[\begin{array}{c}1\\1\end{array}\right]\) and \(\left[\begin{array}{c}1\\-1\end{array}\right]\text{.}\) The general solution is \(\mathbf{x}(t) = C_1 e^{3t}\!\left[\begin{array}{c}1\\1\end{array}\right] + C_2 e^{-t}\!\left[\begin{array}{c}1\\-1\end{array}\right].\) The equilibrium at the origin is a saddle point and therefore unstable.
    🔗
    🔗
    Solution.
    Write the system in matrix form:
    \begin{equation*} \mathbf{x}' = A\mathbf{x},\qquad A = \begin{pmatrix} 1 \amp 2\\ 2 \amp 1 \end{pmatrix}. \end{equation*}
    Compute the characteristic polynomial:
    \begin{equation*} \det(A - \lambda I) = \det\begin{pmatrix}1-\lambda \amp 2\\2 \amp 1-\lambda\end{pmatrix} = (1-\lambda)^2 - 4 = \lambda^2 - 2\lambda - 3. \end{equation*}
    Factor: \(\lambda^2 - 2\lambda - 3 = (\lambda - 3)(\lambda + 1).\) Thus the eigenvalues are \(\lambda_1 = 3\) and \(\lambda_2 = -1\text{.}\)
    🔗
    For \(\lambda_1 = 3\text{,}\) solve \((A - 3I)\mathbf{v} = \mathbf{0}\text{:}\) \(A - 3I = \begin{pmatrix} -2 \amp 2\\ 2 \amp -2 \end{pmatrix},\) which yields eigenvector \(\left[\begin{array}{c}1\\1\end{array}\right].\)
    🔗
    For \(\lambda_2 = -1\text{,}\) solve \((A + I)\mathbf{v} = \mathbf{0}\text{:}\) \(A + I = \begin{pmatrix} 2 \amp 2\\ 2 \amp 2 \end{pmatrix},\) giving eigenvector \(\left[\begin{array}{c}1\\-1\end{array}\right].\)
    🔗

    🔗
